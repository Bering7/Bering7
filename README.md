## Projetos em Destaque

* **Integração e Automação de Processos:** Automação de disparo de mensagens dinâmicas no WhatsApp via Z-API, consumindo dados extraídos do Supabase (PostgreSQL) via requisições HTTP REST. O projeto conta com rastreabilidade através do módulo `logging` nativo do Python e versionamento organizado com Conventional Commits.
* **Controle Térmico de Satélites:** Simulação térmica para satélites em órbita baixa (LEO) construída em Python. O projeto abrange desde a geração estruturada dos dados de temperatura até a análise exploratória, criação de gráficos e elaboração do relatório técnico.
* **Análise de Crédito e Churn:** Análise exploratória de dados focada no setor financeiro. Utilização da biblioteca Pandas para estruturar e identificar padrões comportamentais e motivos de cancelamento de serviços (Churn Analysis).
* **Assistente Virtual com IA:** Desenvolvimento de um chatbot interativo focado em usabilidade de interface e respostas dinâmicas, utilizando o framework Streamlit.
